## Cómo correrlo

```bash
docker compose up --build
```

Y luego abre <http://localhost:8000>. Si hay que bajar datos o modelos antes, pon aquí
el comando exacto (no los subas al repo: van en `datos/` y `modelos/`, que se ignoran).
